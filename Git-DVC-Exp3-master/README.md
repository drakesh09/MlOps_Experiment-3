# Git-DVC-Exp3

## Experiment 3: Git and DVC for Machine Learning Versioning

### Aim

Implement Git for source-code version control and DVC (Data Version Control) for dataset and machine learning model versioning to support reproducible ML experiments.

## Tasks Completed

1. Created a Machine Learning project and initialized a Git repository.
2. Created the project structure and pushed the project to GitHub.
3. Installed and initialized DVC in the Git repository.
4. Downloaded the Iris dataset and tracked it using DVC.
5. Configured a local DVC remote and pushed the dataset to it.
6. Modified the dataset and created a second dataset version.
7. Restored the previous dataset version using Git and DVC.
8. Trained a Random Forest classifier and saved the model.
9. Tracked the trained model using DVC.
10. Trained a second Random Forest model with different hyperparameters and created a second model version.
11. Restored Model v1 and verified reproducibility.
12. Retrieved the dataset and both model versions in another project folder and verified reproducibility.
13. Compared Git and DVC for code, data, model versioning, collaboration, and reproducibility.
